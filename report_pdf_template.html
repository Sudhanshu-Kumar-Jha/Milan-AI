4. GST Compliance, Invoicing & MSME Verification

Statutory accounting guidelines for claiming Input Tax Credit (ITC) under Indian GST law (SAC Codes 998314 / 998315).

📋 Input Tax Credit (ITC) Checklist

1.Valid 15-Digit GSTIN: Vendor must provide authentic GST certificate.
2.Buyer Billing Details: Correct legal entity name & state code matching buyer GSTIN.
3.GSTR-1 to GSTR-2B Reflection: Vendor must upload invoice on GST portal.
4.SAC Code Specification: Appropriate SAC (998314, 998315, 998316).

🏭 MSME Udyam Verification Rules

1.Udyam Certificate: Obtain 19-digit Udyam number (UDYAM-XX-00-0000000).
2.Portal Verification: Verify on https://udyamregistration.gov.in.
3.45-Day Statutory Payment Rule: Settle micro/small vendors within 45 days.
